SITE SIMPLES - SALAS DA ESCOLA

Como executar:

1. Abra a pasta no VS Code.
2. Abra o terminal.
3. Execute:
   npm install

4. Depois execute:
   npm run dev

5. Abra o endereço mostrado pelo Vite.

O site é somente um protótipo simples de front-end.
Não possui banco de dados, back-end ou API.

ACESSO:
- Alunos não fazem login: abrem o site e veem direto o status das salas.
- Login somente para professores e secretaria (botão no topo da página).
